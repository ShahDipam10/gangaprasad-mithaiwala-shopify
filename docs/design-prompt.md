# Design brief — paste this into a fresh Claude session dedicated to design

I'm designing a Shopify storefront for a fictional heritage Indian sweets
brand, for my agency's portfolio. I want you to lead the visual design —
propose a real point of view, don't just execute a brief literally. Ask me
questions if anything's ambiguous. Once we land on a direction, build it as
a mobile-first HTML mockup (using an artifact) so I can actually look at it.

## The brand

**Gangaprasad Mithaiwala** — a Gujarati mithai (sweets) and namkeen
(savory snacks) shop, founded 1919 in Anand, Gujarat (India's dairy
capital), still run by the same family three generations later. Fresh cow's
milk sourced daily from local dairy cooperatives, no preservatives, small
daily batches rather than mass production. Sweets are central to Indian
celebration culture — festivals, weddings, gifting — so the brand should
feel festive and rooted, not like a generic bakery.

Reference points from the original brief (for inspiration, not to copy):
Ajwaah Sweets and Candy Envy (both real Shopify sweet shops with strong
heritage storytelling and clean category browsing), and Shopify's "Sweet"
theme feature set (image galleries, promo banners, trust badges, upsell
widgets).

## Where we've gotten to so far (starting point, not a constraint)

A previous design pass landed on: saffron/maroon/gold/jade as the festive
palette, cream page background, Fraunces (serif) for headings + Poppins
(sans) for body text. That palette and pairing were approved and are
already wired into the actual Shopify theme's color scheme settings — so
there's real value in keeping continuity with it. That said, if you think
the execution of that direction can be meaningfully better (or if a
different direction genuinely serves this brand better), say so and make
the case — I'd rather have your honest opinion than a rehash.

## Real imagery, not illustrated placeholders

This is the most important functional requirement: **use real photography**
for the shop, the founder/family, and every product — not icons, not
illustrated SVG placeholders, not abstract shapes standing in for photos.
If you can search the web or browse for genuinely usable reference/stock
photography (e.g. royalty-free sources like Unsplash/Pexels) of Indian
sweets, mithai shops, dairy farms in Gujarat, etc., use real image URLs
in the mockup. Flag clearly which images are stand-ins for real product
photography we'll shoot later versus ones that could plausibly ship as-is.

## Pages needed (all of them, mobile-first)

1. **Home** — hero, shop-by-category, bestsellers, heritage story, trust
   signals, newsletter signup, footer.
2. **Collection** — one template serving three collections: Sweets,
   Namkeen, Festival Specials. Needs filter/sort, and a product grid.
3. **Product detail** — image gallery, variants (weight: 250g/500g/1kg
   etc.), price, add-to-cart, trust badges, ingredients/shelf-life info,
   related products.
4. **About** — founding story (1919, Anand, three generations), timeline.
5. **Contact** — form, address/phone/hours, map.
6. **FAQ** — accordion covering shelf life, shipping/COD, returns, bulk
   orders, allergens.
7. **Policy** — one shared template for Privacy/Terms/Refund/Shipping
   (this one can and should be visually quiet/utilitarian — it's a legal
   page, not a marketing page).

## Real content to use (don't use lorem ipsum)

**Navigation**: Home · Sweets · Namkeen · Festival Specials · About ·
Contact

**Sample products** (full 20-SKU catalog exists if useful, ask and I'll
share it): Kesar Doodh Peda (₹450/250g), Kaju Katli (₹650/250g), Motichoor
Laddu (₹380/250g), Diwali Mithai Gift Hamper (₹1,500).

**Currency**: Indian Rupees (₹) throughout — this is an India-market store.

## What "done" looks like

A mobile-first mockup (with a real, working sense of how it adapts to
desktop) I can review, covering all 7 templates, using real imagery,
that I can bring back to my Claude Code session for actual Shopify theme
development.
